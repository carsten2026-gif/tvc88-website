VOR DEM ONLINE-GEHEN AUSFÜLLEN
--------------------------------
1. impressum.html  → gelb markierte Felder (Adresse, VR-Nummer, Tel.)
2. kontakt.html    → Formspree-ID einsetzen (oder leer lassen für mailto)
3. img/aufnahmeformular.pdf  → echtes PDF ablegen
4. img/satzung.pdf           → echte Satzung ablegen

FORMSPREE (kostenloses Kontaktformular)
---------------------------------------
1. Konto anlegen: formspree.io
2. Neues Formular → ID kopieren (sieht aus wie: xyzabcde)
3. In kontakt.html Zeile suchen: DEINE-FORMSPREE-ID
4. ID ersetzen → Datei speichern → hochladen → fertig!

HOCHLADEN (FTP)
---------------
Programm: FileZilla (kostenlos, filezilla-project.org)
Alle Dateien in das Stammverzeichnis des Webservers hochladen.
index.html muss im Wurzelverzeichnis liegen (nicht in einem Unterordner).
